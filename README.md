# Allkin Skills

Ready-made competences for your [Allkin](https://allk.in) agents.

A competence is a piece of know-how an agent picks up when a task calls for it: writing a clear
e-mail, taking meeting notes, planning a project, reviewing code, looking after a server, and more.

## Using one

In Allkin, open the **Competences** page — or the page of an agent — and give the agent the
competences you want. Allkin fetches them at that moment; there is nothing else to install.

A competence teaches an agent how to do something. It never lets the agent do more than you
already allowed.
