# Data analysis

For any agent you hand tables to: a CSV, a TSV or an Excel file (.xlsx). The
agent never computes a figure "in its head": scripts profile the file (types,
missing and unreadable cells, duplicates), filter, group and compute — sums,
averages, medians, counts, shares, by category or by month — and draw plain
charts as SVG. The agent then writes a short note: the answer first, the
findings with their figures, and what the data cannot tell.

The scripts run in Allkin's closed frame for competences: Node alone, no
network, they read the agent's folder and write only there. The file to
analyse must be in the agent's folder (an attachment is).

It grants nothing: the agent keeps exactly the rights it has.
