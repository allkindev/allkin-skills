# Textüberarbeitung

Für jeden Agenten, der Texte für andere Leser schreibt. Bevor er Ihnen einen
Text übergibt, überarbeitet er den Entwurf in vier getrennten Durchgängen: den
Aufbau (die Kernaussage, die Reihenfolge, was gestrichen wird), den Satz
(Verben, konkrete Wörter, Rhythmus), die Gewohnheiten, die einen Text maschinell
klingen lassen, und die Oberfläche (Rechtschreibung, Typografie, Einheitlichkeit).
Er bewahrt die Stimme eines Textes, den er für Sie überarbeitet, fügt nie eine
Tatsache hinzu und sagt Ihnen kurz, was er geändert hat und was er nicht prüfen
konnte.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
