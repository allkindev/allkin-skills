# Writing revision

For any agent that writes texts other people will read. Before handing a text
over, it revises the draft in four separate passes: the structure (the point,
the order, what to cut), the sentence (verbs, concrete words, rhythm), the
habits that make a text sound machine-written, and the surface (spelling,
typography, consistency). It keeps the voice of a text it revises for you,
never adds a fact, and tells you briefly what it changed and what it could not
check.

It grants nothing: the agent keeps exactly the rights it has.
