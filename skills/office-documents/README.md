# Word and Excel documents

For any agent you hand Word or Excel documents to. With this competence, the agent reads a
`.docx` or a `.xlsx` — the paragraphs and tables of a document, the sheets and cells of a
workbook —, fills it in, corrects it, formats it (fonts, styles, margins, lists, tables; cell
looks, widths, merges, frozen panes) and creates new ones. A document is changed in place: what
the agent does not touch — styles, pictures, headers, comments, charts — stays exactly as it was,
and you see it change in its tab.

It is the key of the Office tools: an agent that has it gets them, an agent that does not has
none of them — and does not carry their weight in each of its conversations. The agent of the
page asks for it too on a Word or Excel document.

It widens no right: these tools reach the files the agent already reaches — its folder, the
shared folder, the work folder of the conversation —, with no approval. PowerPoint files, `.doc`
and `.xls` are not changed; formulas are computed again when you open the workbook in a
spreadsheet. Only you give it to an agent.
