# Create integrations

For any agent you want to have build integrations for Allkin. With this competence, the agent
designs an integration with you — a page in a tab, a program Allkin keeps running, settings, a
dedicated agent —, writes it in its **workshop** (the `workshop/` folder of its own folder), with
its translations in the four languages, its documentation and its icon, checks it against
Allkin's standard and corrects it until nothing is left to fix. It maintains what it made the
same way, and reads the log of one of its integrations to debug it with you.

It is the key of the workshop tools: an agent that has it gets them — the list of its projects,
their check, the log of its installed integrations —, an agent that does not has none of them.
What the agent writes shows up in the **Integrations** page, **Add** window.

It widens no right: no command, no network, no installation comes with it. **You alone install
and update** what the agent makes, from that window, and grant its rights on its page; the agent
tells you where to click. A third-party software an integration talks to is installed by you,
never by the integration, and its credentials live in a service. Only you give this competence to
an agent.
