# Integrationen erstellen

Für jeden Agenten, den du Integrationen für Allkin bauen lassen willst. Mit dieser Fähigkeit
entwirft der Agent mit dir eine Integration – eine Seite in einem Tab, ein Programm, das Allkin
am Laufen hält, Einstellungen, einen eigenen Agenten –, schreibt sie in seine **Werkstatt** (den
Ordner `workshop/` in seinem eigenen Ordner), mit ihren Übersetzungen in den vier Sprachen, ihrer
Dokumentation und ihrem Symbol, prüft sie nach dem Standard von Allkin und korrigiert sie, bis
nichts mehr zu beheben ist. Was er gebaut hat, pflegt er auf dieselbe Weise, und er liest das
Protokoll einer seiner Integrationen, um sie mit dir zu debuggen.

Sie ist der Schlüssel der Werkstatt-Werkzeuge: Ein Agent mit ihr erhält sie – die Liste seiner
Projekte, ihre Prüfung, das Protokoll seiner installierten Integrationen –, ein Agent ohne sie
hat keines davon. Was der Agent schreibt, erscheint auf der Seite **Integrationen**, im Fenster
**Hinzufügen**.

Sie erweitert kein Recht: Weder Befehle noch Netzwerk noch Installation kommen mit ihr. **Nur du
installierst und aktualisierst**, was der Agent baut, in diesem Fenster, und gewährst die Rechte
auf der Seite der Integration; der Agent sagt dir, wo du klicken musst. Eine Fremdsoftware, mit
der eine Integration spricht, installierst du, nie die Integration, und ihre Zugangsdaten liegen
in einem Dienst. Nur du gibst diese Fähigkeit einem Agenten.
