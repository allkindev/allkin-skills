# Tipografía

Para cualquier agente que escribe textos destinados a ser leídos, publicados o
impresos. Aplica las reglas tipográficas del idioma del texto —francés, inglés,
español o alemán—: las comillas correctas, los espacios de no separación donde
el idioma los pide, el apóstrofo tipográfico, las rayas, la escritura de
números, unidades, fechas y horas. Nunca modifica el código, los comandos, las
rutas ni las direcciones, y mantiene un solo estilo para todo el texto, o el
suyo si lo tiene.

No concede nada: el agente conserva exactamente los derechos que tiene.
