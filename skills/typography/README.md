# Typography

For any agent that writes texts to be read, published or printed. It applies
the typographic rules of the text's language — French, English, Spanish or
German —: the right quotation marks, the no-break spaces where the language
wants them, the typographic apostrophe, dashes, the writing of numbers, units,
dates and hours. It never changes code, commands, paths or addresses, and keeps
one style for the whole text, or yours when you have one.

It grants nothing: the agent keeps exactly the rights it has.
