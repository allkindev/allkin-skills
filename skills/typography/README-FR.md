# Typographie

Pour tout agent qui écrit des textes destinés à être lus, publiés ou imprimés.
Il applique les règles typographiques de la langue du texte — français,
anglais, espagnol ou allemand — : les bons guillemets, les espaces insécables
là où la langue les veut, l'apostrophe typographique, les tirets, l'écriture
des nombres, des unités, des dates et des heures. Il ne modifie jamais le code,
les commandes, les chemins ni les adresses, et garde un seul style pour tout le
texte, ou le vôtre si vous en avez un.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
