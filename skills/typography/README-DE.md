# Typografie

Für jeden Agenten, der Texte zum Lesen, Veröffentlichen oder Drucken schreibt.
Er wendet die typografischen Regeln der Sprache des Textes an – Französisch,
Englisch, Spanisch oder Deutsch –: die richtigen Anführungszeichen, geschützte
Leerzeichen dort, wo die Sprache sie verlangt, den typografischen Apostroph,
Striche, die Schreibweise von Zahlen, Einheiten, Daten und Uhrzeiten. Code,
Befehle, Pfade und Adressen ändert er nie, und er hält einen Stil für den
ganzen Text ein – oder Ihren, wenn Sie einen haben.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
