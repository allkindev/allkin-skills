# Allkin-Administration

Allkin von Grund auf, für einen Agenten, der die Maschine verwaltet: wo Allkin installiert ist,
sein Dienst und seine Protokolle, seine Updates und Sicherungen, sein Ereignisprotokoll, jede
Seite und jede Einstellung der Oberfläche.

Damit:

- **untersucht der Agent Allkin** — den Dienst, seine Protokolle, das Ereignisprotokoll, die
  Festplatte, den Port —, bevor er etwas anfasst;
- **erledigt er mit seinen eigenen Werkzeugen**, wofür Allkin ihm welche gegeben hat: Aktionen,
  Agenten;
- **führt er Sie an die genaue Stelle** der Oberfläche für das, was Ihnen zusteht — ein Recht,
  eine Einstellung, eine zu installierende Integration —, Schritt für Schritt, in Ihrer Sprache;
- **überschreitet er nie die Grenzen von Allkin**: Er vergibt kein Recht (weder sich selbst noch
  einem anderen Agenten), schreibt nichts von Hand in die Konfiguration von Allkin, rührt das
  Ereignisprotokoll nie an, schaltet die Maschine nie aus, hebt nie die Schutzmechanismen von
  Allkin für Firewall oder SSH auf und schneidet nie den Zugang ab.

Sie erweitert kein Recht: Was der Agent auf der Maschine tun kann, bestimmt seine Agentenseite.
