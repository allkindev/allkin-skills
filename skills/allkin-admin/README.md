# Allkin administration

Allkin inside out, for an agent that administers the machine: where Allkin is installed, its
service and its logs, its updates and backups, its event log, every page and every setting of
the interface.

With it, the agent:

- **diagnoses Allkin** — the service, its logs, the event log, the disk, the port — before
  touching anything;
- **does with its own tools** what Allkin gave it tools for: actions, agents;
- **sends you to the exact place** in the interface for what is yours — a right, a setting, an
  integration to install —, step by step, in your language;
- **never crosses Allkin's lines**: it grants no right (to itself or any agent), writes nothing
  by hand in Allkin's configuration, never touches the event log, never shuts the machine down,
  never undoes Allkin's own firewall or SSH guards, never cuts the way in.

It widens no right: what the agent can do on the machine is what its Agent page allows.
