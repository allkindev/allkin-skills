# Administration d'Allkin

Allkin de fond en comble, pour un agent qui administre la machine : où Allkin est installé, son
service et ses journaux, ses mises à jour et ses sauvegardes, son journal d'événements, chaque
page et chaque réglage de l'interface.

Avec elle, l'agent :

- **diagnostique Allkin** — le service, ses journaux, le journal d'événements, le disque, le
  port — avant de toucher à quoi que ce soit ;
- **fait avec ses propres outils** ce pour quoi Allkin lui en a donné : les actions, les agents ;
- **vous mène à l'endroit exact** de l'interface pour ce qui vous revient — un droit, un
  réglage, une intégration à installer —, pas à pas, dans votre langue ;
- **ne franchit jamais les limites d'Allkin** : il n'accorde aucun droit (ni à lui-même ni à un
  autre agent), n'écrit rien à la main dans la configuration d'Allkin, ne touche jamais au
  journal d'événements, n'éteint jamais la machine, ne défait jamais les garde-fous d'Allkin sur
  le pare-feu ou SSH, ne coupe jamais le chemin d'accès.

Elle n'élargit aucun droit : ce que l'agent peut faire sur la machine est ce que sa page Agent
lui permet.
