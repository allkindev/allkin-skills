# Themenbeobachtung

Für jeden Agenten mit Webzugriff, der ein Thema über die Zeit verfolgen soll:
Wettbewerber, Preise, eine Technologie, eine Vorschrift, Erwähnungen eines
Namens. Der Agent richtet die Beobachtung mit Ihnen ein – die Fragen, die
jedes Mal zu beantworten sind, die Quellen, zu denen er zurückkehrt, was eine
Warnung verdient –, hält in Dateien fest, was er bereits gemeldet hat, und
nennt bei jedem Durchlauf nur, was seit dem letzten neu ist. „Nichts Neues“
ist eine Zeile. Mit dem Recht, Aktionen zu planen, läuft die Beobachtung von
selbst.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
