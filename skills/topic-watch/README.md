# Topic watch

For any agent with web access that must follow a subject over time:
competitors, prices, a technology, a regulation, mentions of a name. The agent
sets the watch up with you — the questions to answer each time, the sources to
return to, what deserves an alert —, keeps in files what it already reported,
and at each run tells you only what is new since the last one. "Nothing new"
is one line. With the right to schedule actions, the watch runs on its own.

It grants nothing: the agent keeps exactly the rights it has.
