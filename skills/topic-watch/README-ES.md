# Vigilancia

Para cualquier agente con acceso a la web que deba seguir un tema en el
tiempo: competidores, precios, una tecnología, una normativa, las menciones de
un nombre. El agente configura la vigilancia con usted —las preguntas que
responder cada vez, las fuentes a las que volver, lo que merece una alerta—,
guarda en archivos lo que ya comunicó, y en cada pasada solo le dice lo nuevo
desde la anterior. «Nada nuevo» cabe en una línea. Con el derecho de programar
acciones, la vigilancia funciona sola.

No concede nada: el agente conserva exactamente los derechos que tiene.
