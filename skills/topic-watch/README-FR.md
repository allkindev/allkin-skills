# Veille

Pour tout agent ayant accès au web et qui doit suivre un sujet dans la durée :
des concurrents, des prix, une technologie, une réglementation, les mentions
d'un nom. L'agent met la veille en place avec vous — les questions auxquelles
répondre à chaque fois, les sources à revisiter, ce qui mérite une alerte —,
garde dans des fichiers ce qu'il a déjà signalé, et à chaque passage ne vous
dit que ce qui est nouveau depuis le précédent. « Rien de nouveau » tient en
une ligne. Avec le droit de planifier des actions, la veille tourne toute
seule.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
